# Qwen-Image-2.1 提示词手册（官方案例拆解版）

> 来源：ModelScope《Qwen-Image-2.1 提示词写法指导手册》（alding86，2026-09-23 修订版，基于官方示例库 40 余真实案例逐类拆解，https://www.modelscope.cn/posts/436932）。本文件是本 Skill 配图提示词的**写作权威**；[image-generator.md](image-generator.md) §4.5 的 8 条规则是本手册在本机管线（纯 API 图、无智能改写、cfg=1 负面惰性）下的实例化，两者冲突时以 §4.5 为准。
> 五套可填空骨架见 [`../templates/qwen_prompt_skeletons.md`](../templates/qwen_prompt_skeletons.md)。

主线四步：**先定模式 → 再定详略 → 按骨架分层填写 → 最后补防错约束**。

## 第 0 步：三个前置判断

1. **模式**：不带输入图 = 文生图（从零描述完整画面）；带 1–10 张输入图 = 图像编辑（用「第 1—N 张图」或 `<image1>` 按上传顺序引用并交代角色——谁是场景、谁是物品、谁是人物身份）。deck 管线中对应 `--reference-image`，装配细则见 §4.5 规则 8。
2. **详略（智能改写 Prompt Extend 开关是分水岭）**：关闭改写 → 逐元素逐字锁定、把画面信息说尽；开启改写 → 只给主题/风格/结构/约束骨架。错配必翻车。**本机管线无 Prompt Extend ⇒ 永远走关闭改写的全细节锁定分支**。判断依据是"需逐字锁定"还是"允许扩写"，不是"文生图就开、编辑就关"。
3. **特殊输出的官方固定句式**（原样套用，只替换画面描述）：
   - **透明图 RGBA**：首句「这是一张带有透明度的 RGBA 图像……」，末句「该图像具有 alpha 通道，背景是透明的。」英文 "This is an RGBA image with transparency. … The image has alpha channel and the background is transparent."——即 §4.5 三槽包装器的官方出处；deck 资产用 §4.5 的英文条款（本机 alpha 行为已验证键定在英文上）。
   - **360° 全景**：必须写明 `true equirectangular projection`、360° 水平 / 180° 垂直视野、左右边缘无缝、输出 2880×1440 严格 2:1。

## 通用分层骨架（所有文生图）

按序展开，越靠前显著度权重越高：**身份锚定句**（"这是一张……讲解图板/随手拍生活照/广告摄影"）→ **主体**（外观姿态占比）→ **环境**（前景背景）→ **光照**（方向时段冷暖光比）→ **材质纹理**（具体名词+数值替代空泛形容词："带猫眼光泽的棕黄色虎眼石圆珠""9:16 竖条"）→ **构图**（视角焦段横竖版）→ **风格收束**（日系二次元/CCD 直出/印象派）→ **排除项写进正文**（"无文字、无 logo、无水印""不拆成多格"；官方案例不用通用负面框架，本机 cfg=1 负面惰性，排除项进 positive 是唯一有效途径，即 §4.5 规则 6/7 的依据）。

deck 装配提醒：PPT 的文字一律走原生 SVG/PPTX 层，画面内不烘焙文字（§4.5 强制无文字条款），故 deck 场景下本手册主要用到分层骨架 + 留空区点名两件事；以下专项分支服务非 deck 的直出需求（海报页、单张插图交付等）。

## 文字密集型画面（信息图 / 海报 / App 界面 / 科普卡）

- 逐字锁定文案：标题、图例、坐标轴刻度、表格数值、UI 状态栏时间全部原文写出；文字越确定，乱码越少（本机实测：9 处中文文案逐字全对，含「92℃」度数符）。
- 先划区再填空：(a)(b)(c) 分区编号逐区填写，防元素挤占。
- 字体族与层级明说（"标题粗黑体、正文宋体"）。
- 防乱码三件套收尾：①逐字准确清晰可读无错字乱码；②不生成未指定的多余文字；③不添加未要求的口号标语。

## 图像编辑类

指令链：引用输入图并交代角色 → "保持【逐项清单】完全不变"（材质/每行 logo/纹理；涉人固定写"严格保持面容、五官、气质不变"）→ 移除【…】 → 新增/替换【…】逐元素描述 → **统一光影逻辑**（接触阴影方向、同侧光明暗过渡——漏写是画面假感头号原因）→ 其余与输入图一致、不重绘不重新构图。
局部编辑（圈选/掩码/涂抹）："区域—动作"一一对应 + "标注线不得渲染进图像"。

## 多参考图协同（≤10 张）

- 多人合照：每张人脸为身份参考 → 逐人指派服装/姿态/站位 → 锁定易变细节（"保持 `<image1>` 发型完全不变，不得改成披肩长卷"）→ 统一场景收束。
- 换装穿戴：图号—物品—穿戴动作对应清楚（"让【图1】模特换上【图3】的鞋"）+ 锁定姿势与背景。
- 多物布置：空场景为底 + 逐件"取哪图的什么物、放何处、朝向、遮挡" + "只取物体本身、忽略原背景" + 统一到场景光照。

## 分镜 / 故事板 / 时间轴

- 格数排布硬约束："恰好 N 格、等宽同高、1 行 N 列、每格竖长条、绝不把任何一格再拆成上下两块"；编号防错句"每格一个数字徽标，不重复不跳号不缺号"（本机实测：6 格约束全数生效）。
- 角色一致性锚定：三视图基准、发型服饰全程一致、只改姿势表情场景、"每格必须画出角色本人、严禁只有背景的空格"。
- 逐格脚本化 + 镜头节奏（全景—中景—近景—特写）或时间分段。

## 人物一致性与摄影质感

- 真人迁移："以输入图片中这位××为身份基准，五官发型沿用原图不变，仅重建其余部分"。
- 摄影参数感：机位高度、焦段景深写实。
- 介质词锁质感："CCD 卡片机正面直闪、跑焦、暗角噪点"/"手机随手拍"/"印象派油画 broken color impasto"（转绘须声明"保留构图、比例与可辨识文字"）。

## 避坑清单

1. 改写开关与详略错配（本机恒为锁定分支，不适用）。
2. 文字图忘防乱码三件套。
3. 编辑类漏保持清单或漏光影统一。
4. 分镜不写格数/排布/编号硬约束。
5. 用形容词代替具体材质、光线角度、数值。
6. 官方 vs 非官方：`#FF4500` 色码、"8k/超高清"画质词、通用负面框架、常规比例预设均属经验补充，非官方规范。

## alpha 验证纪律（本机实测）

留空区达标与否，测量区域必须按资产配方划定——主体剪贴类（§4.5 配方 A）量声明空区整高矩形；边缘装饰类（配方 B）的顶/底横带本就设计为横贯全宽，只能量中央文字区（约 x10–90% × y25–75%），拿整侧去量会把合规图误判为漏白（实例：B 图整侧量得 28.7% 不透明，改量中心区实为 0.00%）。空区 1–4/255 微雾属正常，像素级干净用 `alpha<8→0` 阈值。
