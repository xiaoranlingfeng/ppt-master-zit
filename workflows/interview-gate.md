# 逐项决策门禁（PPT Interview Gate）

把 grill-me 的访谈方法接到 PPT Master 的既有阶段上：**不新增路由、不绕过确认门禁**，而是在既有 ⛔ BLOCKING 门禁之前，把每一项实体决定一次问一项地问出来，然后一次性确认。

方法来源：`grill-me` 技能（一次一问 / 每题 2–5 个具体选项 / 能自己查的不问用户 / 结束后给决策摘要）。本文件只规定「问什么、在哪问、答案落到哪个产物」，不改变各路由的执行权威。

---

## 0. 触发与边界

| 条件 | 行为 |
|---|---|
| 用户明说「grill me」「逐项确认」「别替我决定」「我要自己定大纲/页数/每页内容/动画」 | 必须走本门禁 |
| Generate PPTX 路由、非 Image-to-PPTX、非 Quick | 默认走本门禁（这是本机默认行为） |
| 用户明说「Quick」「直接生成」「别问了」 | 跳过本门禁，按 `quick-generate.md` 执行 |
| Image to PPTX / Beautify 的 Quick 路径 | 不适用（源事实或源页序已冻结） |
| Edit Native PPTX | 只在 §3 的 D6 处适用 |

**硬规则 — 一次一问**：每个问题都必须通过提问工具以多选题呈现（用户总可自填），不要用普通文本抛问题；问完一项得到答复后，用一句确认，再问下一项。

**硬规则 — 能自己查的不问**：页数/大纲/内容等若源文件里已有答案，直接查，然后只问「保留还是改」这一个决策，不要重问事实。

**硬规则 — 不越过既有门禁**：本文件产生的答案汇总为**一次**门禁提交，仍须遵守 `generate-pptx.md` 的「两阶段确认」「只有用户确认」纪律；不得代替用户确认。

**默认模型**：本地 ComfyUI 配图的默认模型固定为 **Qwen-Image-2.1**（`COMFY_MODEL=qwen`）。D5 只在用户想换模型时改动它。

---

## 1. 决策清单（按依赖顺序，一次一问）

依赖顺序不可打乱：大纲决定页数，页数决定每页内容与图像额度，图像方式决定用哪个提示词权威，动画在页数与内容定稿后才问。

| ID | 决策 | 关键选项（示例，按实际项目裁剪） | 落到哪个产物 |
|---|---|---|---|
| **D0** | 沟通契约 | 受众 / 使用场景（现场讲、自学、录屏、视频）；建议 3 个方向 | Stage-1 契约、`design_spec.md §I` |
| **D1** | 模板模式 | `free_design` / 某个 Brand·Style·Layout·Deck 工作区 | Stage-1 选择 |
| **D2** | 大纲 | 结构方案 A/B/C（例如「问题—证据—方案—行动」vs「时间线叙事」vs「按模块平铺」）；章节数 | `design_spec.md §IX` 的章节骨架 |
| **D3** | 页数 | 用户给定量 / 按内容密度推荐区间（如 12–14 页）/ 自动 | Stage-1 页数范围、§IX 条目数 |
| **D4** | 每页内容 | 逐页确认：标题、一句核心信息、要点数、承载体（图表/表格/图片/文字块） | §IX 每页 block、`page_rhythm` |
| **D5** | 图像使用方式 | (a) 不用 AI 图 (b) 只用用户素材 (c) 题图/章节图 AI 配图 (d) 全文 AI 配图 (e) AI 插画元素 + 切片；并选模型：**Qwen-Image-2.1（默认）** / MOSS-Image SFT / Z-Image Turbo；出图档位按 §VIII 声明尺寸定：**≤1280px 用 `1K`（默认）**、1280–2560 用 `2K`、>2560 用 `4K` | §VIII 每一行 `Acquire Via`、`page_role`、`text_policy`，以及 manifest 的 `image_size` |
| **D6** | 切换动画 | 无 / 淡入（默认 0.4s）/ 推入 / 擦除 / **Morph**（需要成对页，必须在写页面前定）/ 随机 | 导出命令的 `-t`；Morph 另需成对页 |
| **D7** | 元素动画 | 关闭（默认）/ 统一入场（`-a auto`）/ 逐页定制（`animations.json`，多问 1–2 项即可，细节留到 `customize-animations`） | `-a` 或 `animations.json`；`design_spec.md §I` 的 Custom Animations 开关 |
| **D8** | 节奏与放映 | 手动翻页 / 自动播放（秒数）/ 带旁白音频 / 循环展台（`--kiosk`） | `--auto-advance`、`--kiosk`、Narration Audio 开关 |
| **D9** | 交付物 | 仅 PPTX / PPTX + 旁白音频 / PPTX + MP4 | 导出阶段 |

### 依赖的强制规则

- **D3 不得早于 D2**：页数是大纲的函数；用户给了页数而内容装不下时，指出冲突并让用户在「加页」与「减内容」之间二选一，不要默默压缩。
- **D4 一次一页**：逐页问，不要一次列出全部页面让用户圈选。每页问「这一页要传达什么」优先于问「放什么图」。
- **D6 的 Morph 是写页面前的决定**：选 Morph 必须在 Step 6 授权前确定成对页，之后无法由导出补出端点状态（见 `animations.md`）。
- **D5 选 MOSS 时**：提示词权威切换为 `moss-image-prompt-enhancer` 技能（见 `image-generator.md §4.5`）；选 Qwen 时走本 skill 自带的 RGBA 提示词规则。不要在 D5 之后再换模型，否则已写的提示词全部作废。
- **D5 是一套 deck 唯一的模型提问点**：这里定下的模型就是 `image-generator.md §4.5` 那条 ⛔ BLOCKING 要的答案，出图阶段不再重复问，只在用户明说「换模型」时重开。用户选「你决定」时，记录值为 `.env` 的 `COMFY_MODEL`（默认 qwen），Qwen 权重仅限非商用这条风险提示仍要说一次。
- **D5 的出图尺寸不是"越清晰越好"**：`1K`→`2K` 是 4 倍像素、实测 5 倍耗时（16.0s → 80.1s/张，Qwen-Image-2.1 @3080）。1280×720 画布一律 `1K`，别默认 `2K`。改 `image_size` 会让该行的签名失效并触发重出，所以这一档要在写 manifest 时一次定对。

## 2. 执行位置（写进既有路由的哪一步）

| 路由 / 步骤 | 插入点 | 覆盖的决策 |
|---|---|---|
| `generate-pptx.md` Step 3（模板候选准备后、Stage 1 之前） | 先问 D0–D3，把答案作为 Stage-1 契约与大纲的预填值 | D0–D3 |
| `generate-pptx.md` Step 4（Stage 2 授权前） | 问 D5–D9，答案进入 Stage 2 的生产机制 | D5–D9 |
| `generate-pptx.md` Step 4 §IX 定稿后、Step 6 授权前 | 逐页确认 D4 | D4 |
| `edit-native-pptx.md` §4 计划门禁 | 只问 D4（页序/内容映射）+ D7–D8（动画、放映） | D4、D7、D8 |
| `create-template.md` Step 2 门禁 | 只问 D1 延续的 kind / scope / replication_mode，不出大纲与页数 | — |

**汇总提交**：每组的答案合并为对应的既有门禁提交（Stage 1 或 Stage 2），不在门禁之外另开提交点。上面表格里的文件路径均相对于本 skill 根目录。

---

## 3. 结束条件

当 D0–D9 中所有适用项都有明确答复（含用户显式选择「你决定」的项，此时由代理记录为「委托」）时，给出**决策摘要**：一张表列出每个决策 ID、选定的值、以及落到哪个产物；随后进入对应的既有门禁。任何一项未答复都不得视为已确认。

```
D0 沟通契约  → 现场宣讲，管理层 15 分钟
D1 模板模式  → free_design
D2 大纲      → 方案 B（时间线叙事），4 章
D3 页数      → 13 页（含封面 / 章节页×4 / 结语）
D4 每页内容  → 逐页已确认（见 §IX 定稿）
D5 图像      → (c) 题图 AI 配图，模型 Qwen-Image-2.1（默认）
D6 切换      → fade 0.4s
D7 元素动画  → 关闭
D8 放映      → 手动翻页
D9 交付物    → 仅 PPTX
```
