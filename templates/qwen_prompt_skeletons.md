# Qwen-Image-2.1 五套提示词骨架（提炼自官方案例）

【】内为需替换的变量。与 [references/qwen-image-2-1-prompting.md](../references/qwen-image-2-1-prompting.md) 第 0 步判断联动：先定模式，再选骨架。本机 ComfyUI 管线无智能改写，默认走一、三、四、五的全锁定写法；骨架二仅适用于开启 Prompt Extend 的云端入口。

## 一、文生图骨架（关闭改写 · 全细节锁定版）

```
这是一张【品类/风格】的【横/竖版】图。【主体外观与姿态】，处于【环境与前景背景元素】，
【光照：方向/时段/冷暖/光比】，【材质与纹理细节】，【构图：视角/焦段/主体占比与位置】。
【文字区：逐字文案 + 分区位置 + 字体族与层级】。
整体【风格与质感收束】。【排除项：无文字水印 / 无多余元素 / 不拆成多格 / …】。
```

deck 用 16:9 RGBA 资产时，本骨架外面再套 §4.5 三槽英文包装（首句 RGBA 声明 → 中文画面描述 → 留空区点名 + alpha 收尾句 + 无文字条款）。

## 二、文生图骨架（开启改写 · 大纲版）

```
主题与风格一句话：【……】。
关键要素清单：题材【】、人物【】、场景【】、道具【】、配色【】、字体偏好【】。
结构要求：【分格数 / 时间轴 / 版式】。
一致性约束：角色不崩、画风统一【】。
```

## 三、图像编辑骨架（关闭改写）

```
以 <image1>【及其角色：场景/人物/物品】为基础【，<image2>—<imageN> 分别为【…】】。
保持【逐项清单：材质/每一行 logo 文字/纹理/底布/领口…】完全不变【；严格保持面容、五官、气质不变】。
移除【…】。新增/替换为【…】并逐元素描述。
光影统一【：光源方向一致、接触阴影朝【】侧延伸、明暗过渡一致】。
画面其余部分与输入图完全一致，不重绘、不重新构图。
```

局部编辑变体：【圈选/白色掩码/画圈】区域内【期望结果，区域—动作一一对应】；标注线不得渲染进图像。

## 四、信息图 / 科普卡骨架（关闭改写）

```
这是一张【主题】的【信息图/科普卡/海报】，【底色与配色体系】，【整体版式风格】。
版面分区：
  (a)【左上区：标题逐字「…」，字体…】
  (b)【主体面板：图表类型、坐标轴刻度逐值、表格每行数值逐字「…」】
  (c)【右侧竖栏：图例/单位/注记逐字「…」】
字体层级：标题【粗黑体】、正文【宋体】、强调【…】。
所有文字逐字准确、清晰可读、无错字无乱码；不要生成任何未指定的多余文字；不要添加未要求的口号或标语。
```

## 五、分镜 / 故事板骨架

```
画风定调：【……】。
结构硬约束：恰好【N】格、【等宽/同高】、【1 行 N 列，单横排】、每格【竖长条 x: y】，
不是网格、不是两行、绝不把任何一格再拆成上下两块；每格一个数字徽标，不重复、不跳号、不缺号。
角色一致性：以【参考图正面/侧面/背面三视图】为准，发型、服饰、身材比例全程一致，
只改变姿势、表情、动作与所处场景；每一格都必须画出角色本人、占画面主体，严禁只有背景的空格。
逐格脚本：第 1 格【场景+动作】；第 2 格【…】……【或时间轴分段：对峙 0—20s / 激战 21—50s / 落幕 51—90s】。
镜头节奏：【全景—中景—近景—特写】。
收束：画风全程统一，人物不崩。
```

## 附：特殊输出固定句式

- RGBA 透明图（官方口径）：首句「这是一张带有透明度的 RGBA 图像……」+ 画面描述 + 末句「该图像具有 alpha 通道，背景是透明的。」
  英文："This is an RGBA image with transparency. … The image has alpha channel and the background is transparent."
- 360° 全景（官方口径）：`true equirectangular projection`、360° 水平视野、180° 垂直视野、左右边缘无缝、输出 2880×1440 严格 2:1。
